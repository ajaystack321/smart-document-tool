# User Manual

## 1. Image → PDF

1. Open Image → PDF.
2. Upload one or more images.
3. Select A4 or Original.
4. Set quality.
5. Click Create PDF.
6. Download the PDF.

## 2. PDF → Image

1. Open PDF → Image.
2. Upload PDF.
3. Select DPI.
4. Click Convert PDF.
5. Download the image.
6. For multiple pages, download ZIP.

## 3. Scan Anything

1. Upload document/photo.
2. Keep Auto Crop enabled.
3. Select Document filter.
4. Check Before/After preview.
5. Download JPG or PDF.

## 4. Compress Photo

1. Upload photo.
2. Select maximum KB.
3. Select maximum dimension.
4. Click Compress Photo.
5. Check output size.
6. Download.

## 5. Government Form

Always read the website's requirements first.

Check:

- Maximum KB
- Width
- Height
- Format
- Aspect ratio
- Background
- DPI

# User Manual

## 1. Image → PDF

1. Open **Image → PDF**.
2. Upload one or more images.
3. Select **A4** or **Original** page size.
4. Set the required image quality.
5. Click **Create PDF**.
6. Download the generated PDF.

## 2. PDF → Image

1. Open **PDF → Image**.
2. Upload a PDF file.
3. Select the required DPI.
4. Click **Convert PDF**.
5. Download the converted image.
6. For multi-page PDFs, download the ZIP file containing all images.

## 3. Scan Anything

1. Open **Scan Anything**.
2. Upload a document or photo.
3. Choose whether to enable **Auto Crop**.
4. Choose whether to enable **Perspective Correction**.
5. Select the required filter.

### Available Filters

- Document
- Original
- B&W
- Gray
- Light Enhancement
- Outline
- Color Tone
- Brightness Tone
- Blur Removal
- Sharpen
- Skin Tone Sharpen
- Enhance

6. Check the **Before / After** preview.
7. Download the processed image as JPG or PDF.

### Auto Crop

Enable **Auto Crop** to automatically detect and crop the document area.

### Perspective Correction

Enable **Perspective Correction** to correct tilted or angled document photos.

Both options can be enabled or disabled independently according to your requirement.

## 4. Compress Photo

1. Open **Compress Photo**.
2. Upload a photo.
3. Select the maximum target size.
4. Available target sizes start from **20 KB** and increase in **50 KB steps up to 1000 KB**.
5. Select the maximum image dimension.
6. Click **Compress Photo**.
7. Check the output file size.
8. Download the compressed photo.

## 5. PDF Tools

The PDF Tools section provides the following operations:

### Merge PDF

1. Upload multiple PDF files.
2. Arrange them in the required order.
3. Click **Merge**.
4. Download the merged PDF.

### Compress PDF

1. Upload a PDF.
2. Select the required compression option.
3. Compress the PDF.
4. Download the compressed PDF.

### Split PDF

1. Upload a PDF.
2. Select the required pages.
3. Split the PDF.
4. Download the resulting files.

### Delete Pages

1. Upload a PDF.
2. Select the pages to remove.
3. Apply the changes.
4. Download the updated PDF.

### Reorder Pages

1. Upload a PDF.
2. Arrange the pages in the required order.
3. Apply the changes.
4. Download the reordered PDF.

### Rotate Pages

1. Upload a PDF.
2. Select the pages to rotate.
3. Choose the rotation angle.
4. Apply the changes.
5. Download the rotated PDF.

## 6. Government Form

Before uploading or submitting a document for a government form, always read the official website's requirements carefully.

Check the following requirements:

- Maximum file size (KB)
- Image width
- Image height
- File format
- Aspect ratio
- Background requirements
- DPI
- Photo/signature requirements
- Any specific cropping requirements

If a specific KB size is required, use **Compress Photo** to reduce the image to the required size.

Always verify the final file against the official form requirements before submission.

## 7. General Tips

- Use a clear and properly lit photo.
- Keep the document flat when taking a photo.
- Avoid unnecessary shadows.
- Use **Auto Crop** when you want automatic document cropping.
- Use **Perspective Correction** when the document is photographed at an angle.
- Use **B&W** or **Document** filters for scanned documents.
- Use **Sharpen** or **Blur Removal** when the image needs more clarity.
- Check the Before / After preview before downloading.
- Always verify the final file size and dimensions before uploading it to another website.

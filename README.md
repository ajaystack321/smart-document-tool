# Smart Document & Image Toolkit

A lightweight Streamlit application for document and image processing.

## Features

- Image to PDF
- PDF to Image
- Scan Anything
- Automatic document crop
- Perspective correction
- Document filter
- Black & White filter
- Grayscale filter
- Image enhancement
- Photo compression
- Government-form size presets
- ZIP download for multi-page PDFs

## Technology

- Python
- Streamlit
- Pillow
- OpenCV
- NumPy
- PyMuPDF

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
